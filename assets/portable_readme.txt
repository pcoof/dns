# DNS Tester 便携版

## 使用说明

这是 DNS Tester 的便携版本，无需安装即可使用。

### 文件说明

| 文件 | 说明 |
|------|------|
| DNS-Tester.exe | 主程序 |
| dns_config.ini | DNS 服务器配置（预置多类别列表，可自行编辑） |
| dns_tester.log | 运行日志（首次运行自动写入） |
| README.md | 项目说明文档 |
| LICENSE | 许可证 |
| 便携版说明.txt | 本文件 |

### 使用方法

1. 直接双击 DNS-Tester.exe 运行程序
2. 首次运行会请求管理员权限（修改系统 DNS 设置必需）
3. 配置文件、历史记录与日志均保存在程序所在目录，删除整个文件夹即可彻底卸载

### 系统要求

- Windows 10 / 11（64 位）
- 无需安装任何运行时或依赖

### 注意事项

- 便携版可以放在 U 盘等移动存储设备中使用
- 建议将整个文件夹复制到本地硬盘使用以获得最佳性能
- 配置文件被程序占用时，请先退出程序再编辑
