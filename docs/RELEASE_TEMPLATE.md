## ✨ 主要功能

- 🔍 **DNS延迟测试** - 实时测试DNS服务器响应时间
- 🌐 **IPv4/IPv6支持** - 完整支持双栈网络环境  
- 🔧 **网络适配器管理** - 智能检测和配置网络接口
- ⚙️ **系统DNS设置** - 一键切换系统DNS配置
- 🎨 **现代化界面** - 基于ttkbootstrap的美观UI
- 📊 **多类别管理** - 支持DNS服务器分类管理

## 💡 使用提示

### 单文件版 (DNS-Tester.exe)
- 直接运行，无需解压
- 体积最小，适合临时使用
- 配置文件会在程序目录自动创建

### 便携版 (DNS-Tester-Portable.zip)
- 解压到任意目录即可使用
- 包含预配置的DNS服务器列表
- 适合U盘携带或网络分发
- 所有配置保存在程序目录

### 安装版 (DNS-Tester-Setup.exe)
- 完整的Windows安装体验
- 自动创建开始菜单和桌面快捷方式
- 支持标准的添加/删除程序卸载
- 适合长期使用
